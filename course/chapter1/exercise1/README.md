# Retrieval Augmented Generation

Welcome to "Learn Retrieval Augmented Generation"... or "RAG" for short. Applications need search, and in the age of AI, search has become a _lot_ better, but also more complex.

In this course, **you'll learn how to build [retrieval augmented generation](https://en.wikipedia.org/wiki/Retrieval-augmented_generation) systems** using practical strategies, tools, and techniques for modern AI-powered search and retrieval.

## [!windows] for Windows Users

> [!warning]
> If you try to complete this course without [WSL 2](https://docs.microsoft.com/en-us/windows/wsl/install) installed on Windows, you're gonna have a bad time.

## Boot.dev CLI

You'll use the [Boot.dev CLI](https://github.com/bootdotdev/bootdev?tab=readme-ov-file#installation) to test work on your machine. Install it, then verify the installation and log in:

```bash
bootdev --version
bootdev login
```

You'll find each lesson's CLI commands in the test panel. The CLI has two modes:

- `bootdev run <id>` runs checks without submitting.
- `bootdev run -s <id>` submits your work and marks the lesson complete when it passes.

## Assignment

Once the CLI is installed and you're logged in, copy the `run` command from the test panel into your terminal and execute it. If it prints `it's rag, not ai slop`, run the `submit` command.
